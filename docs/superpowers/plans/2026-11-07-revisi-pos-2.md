# Revisi POS Putaran Kedua Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** POS dengan enam palet warna, mode terang/gelap/otomatis, tata letak responsif, dan fitur sesuai PDF: Riwayat, Retur untuk Kasir, Penerimaan baru, Detail Barang, Open Bill, Karyawan dan laporan shift, Biaya, Pelanggan, dan Pengaturan.

**Architecture:** Tema dan mode dibangkitkan dari `tokens/tokens.json` lewat `build-tokens` (atribut `data-pos-theme` dan `data-pos-scheme`). Tata letak responsif CSS lebih dulu dengan dua titik henti (900 dan 600 px) dan satu pola dua panel (`.pos-split`). Fitur baru ditambahkan sebagai modul domain murni yang diuji unit, dihubungkan ke `PosSession`, lalu ke layar; layar sekunder dimuat malas supaya JS awal tetap di anggaran.

**Tech Stack:** TypeScript vanilla, Vite, Vitest (happy-dom), Playwright, axe, token build script (`scripts/build-tokens.mjs`).

**Spec:** `docs/superpowers/specs/2026-11-07-revisi-pos-2-design.md`. Spec dan rencana ini mengikuti putaran pertama (`2026-11-07-revisi-pos-design.md` dan `2026-11-07-revisi-pos.md`, sudah di `main`).

## Review Focus

1. Penyimpanan diblokir atau `matchMedia` tidak ada: mode `otomatis` jatuh ke terang tanpa galat, dan nilai tersimpan rusak atau tema `gelap` lama tidak merusak tampilan (Task 1, 3).
2. Diskon dan harga ekstrem: persen di atas 100 atau negatif, nominal melebihi jumlah baris, harga nol atau negatif, dan retur atas baris berdiskon tidak boleh menghasilkan nilai negatif atau lebih besar dari yang dibayar (Task 16).
3. Dua baris metode sama dengan kanal berbeda (Transfer BCA dan Transfer BRI) tidak saling menimpa, dan hitungan sisa, kembalian, serta laporan shift memandang keduanya (Task 7, 15, 21).
4. Split dan merge bill pada batas: memindahkan semua baris, jumlah melebihi isi, barang sama dengan satuan berbeda, dan bill sumber sama dengan target (Task 19).
5. Lebar 360 px dengan nama panjang (CV Laut Mas, Bu Sherly Tjoandra, nama barang 40 karakter): tidak ada scroll horizontal dan tidak ada teks terpotong pada layar mana pun. Hitungan uang tunai di laci 0 atau lebih besar dari saldo juga tidak merusak laporan (Task 4, 5, 22).
