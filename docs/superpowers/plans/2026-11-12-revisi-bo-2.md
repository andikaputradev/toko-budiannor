# Revisi Back Office Putaran Kedua: Rencana Implementasi

> **Untuk pelaksana:** wajib memakai superpowers:subagent-driven-development (disarankan) atau superpowers:executing-plans. Langkah memakai kotak centang (`- [ ]`).

**Tujuan:** menerapkan seluruh poin dokumen "Revisi Penyesuain Back Office" (K1 sampai K5, D1 sampai D3, B1 sampai B8) beserta syarat tanpa scroll pada semua halaman Back Office.

**Arsitektur:** shell Back Office menjadi persisten (menu laci, header baru, bilah tab) dan setiap tab memegang layarnya sendiri; logika baru (tab, satuan, promo, komisi, riwayat, ekspor) ditulis sebagai fungsi murni yang diuji Vitest; tata letak diuji dengan skrip ukur dan Playwright pada build produksi.

**Tech Stack:** TypeScript murni, Vite 8, Vitest 5, Playwright 1.64 (Chrome terpasang), CSS biasa dengan token, tanpa framework.

**Spec:** `docs/superpowers/specs/2026-11-12-revisi-bo-2-design.md`

## Global Constraints

- CSP `style-src 'self'`: tanpa atribut `style`, tanpa `innerHTML`; lebar dinamis lewat CSSOM atau atribut SVG.
- Anggaran per aplikasi: JS awal 70 KB gzip, CSS awal 25 KB gzip (`npm run budget`); layar sekunder dimuat malas lewat `import()`.
- Teks baru di `src/shared/labels/*.ts`, lalu `node scripts/sync-teks-baru.mjs`; tanpa tanda pisah en dan em (`npm run lint:teks`); 120 pesan sistem terkunci (`messages.ts`).
- Target sentuh 48 px pada tombol utama; axe WCAG 2.x A dan AA; kontras lewat `npm run kontras`.
- Layar acuan 1366 x 640; uji "tanpa scroll" pada 1366x640, 1280x720, 1366x768, 1920x1080.
- Setiap layar tetap mengembalikan `ScreenHandle` (`element`, `destroy`).
- Verifikasi akhir memakai build produksi (`npm run build`, lalu `vite preview` yang memberi header CSP); server dev membuang CSP.
- Satu commit per tugas, pesan berbahasa Indonesia berawalan `feat:`, `test:`, `docs:`, atau `fix:`, berakhiran `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Baris satuan tidak lengkap atau ganda** (Data Barang): baris 2 terisi tetapi satuan dasar dikosongkan, kode ganda tanpa membedakan huruf besar kecil, konversi `0`, `-3`, `12,5`, atau teks. Harapan: baris di bawah baris kosong dibersihkan, masalah ditandai pada baris yang salah, simpan ditolak.
2. **Persen promo dan komisi di luar batas**: `100` (harga nol), `101`, `-5`, `abc`, `20%`, `20,5`, kosong. Harapan: kosong berarti tidak diisi, `20%` dan `20,5` diterima, selebihnya ditolak dengan pesan pada kolomnya.
3. **Tab dan rute berquery**: menutup tab terakhir selain Dashboard, menutup tab aktif saat tab lain tersedia di kanan dan kiri, `Lihat Semua` ke `/bo/stok` ketika tab `/bo/stok?filter=minimum` sudah terbuka, tab ke-11. Harapan: Dashboard tidak pernah tertutup, tetangga kanan lalu kiri yang aktif, isi tab dirender ulang hanya bila query berbeda, tab nonaktif terlama keluar.
4. **Riwayat dan ekspor kosong atau terbalik**: Info dengan rentang `Dari` lebih besar dari `Sampai`, barang tanpa riwayat, Cetak dengan filter yang tidak menyisakan baris. Harapan: rentang ditukar otomatis, tampil keadaan kosong, tombol keluaran menolak dengan pesan MSG-069 yang sudah ada.
5. **Pergantian peran saat layar terbuka**: Owner membuka Data Barang lalu Panel Simulasi mengganti ke Supervisor, atau Keluar dengan banyak tab terbuka. Harapan: seluruh tab dibuang dan dirender ulang sesuai peran baru, kolom HPP dan Harga Beli Akhir tidak pernah muncul untuk Supervisor, login berikutnya hanya memuat tab Dashboard.
