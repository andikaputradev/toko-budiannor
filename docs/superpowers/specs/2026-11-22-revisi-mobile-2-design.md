## 2. Perubahan teknis

- Modul bersama baru: `shared/ui/stock-browser.ts` dan `shared/domain/stock-browse.ts` (daftar stok dua peran), `shared/ui/barcode-scan.ts`, `shared/ui/mob-bar-chart.ts`, `shared/ui/product-search.ts` dan `shared/ui/action-bar.ts` (dipindah dari Owner supaya dipakai Sales), `shared/domain/phone.ts`. CSS baru `styles/mobile-stock.css` dan `styles/mobile-form.css`.
- Owner: `screens/send-doc.ts`, `screens/payment-detail.ts`, `domain/doc-copy.ts`, `domain/payment-history.ts`; sesi mencatat `DebtPaymentRecord` (`BPT-001`, `BHT-001`) lewat `store.addDebtPayment`, `sendOrderCopy`, dan `PurchaseOrder.payment`.
- Teks baru ada di `shared/labels/mobile-revisi2.ts` dan dibaca lewat `mt()` (`shared/mobile-text.ts`), bukan `label()`, agar paket label bersama (dipakai POS dan BO) tidak membengkak. Anggaran JS awal akhir: POS 69,94, BO 69,75, Owner 66,5, Sales 68,2 dari 70 KB.
- Dihapus: kartu katalog Sales lama (pilihan tier, kartu Lihat Order, kontrol per kartu), CSS `trx-stock` dan `mob-viewer`, penampil foto dengan tabel harga dan tombol perbesar.

## 3. Verifikasi

- `npx vitest run`: seluruh tes unit hijau, termasuk `tests/unit/mobile/stock-browse.test.ts` dan `tests/unit/owner/revisi-mobile2.test.ts`.
- `npm run build` dan `npm run budget`: semua aplikasi dalam anggaran.
- e2e `owner.spec.ts` dan `sales.spec.ts` (hp-360x800) hijau kecuali dua tes tema Sales yang sudah gagal sebelum revisi (mengharapkan enam palet padahal ada delapan). Audit axe `OWN-04 /owner/laporan` juga sudah gagal sebelum revisi (kontras `.mob-avatar`).
- Tangkapan layar 390 x 844 setiap layar yang berubah diperiksa satu per satu.
